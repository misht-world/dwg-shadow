DwgShadow — building shadows for AutoCAD 2021–2024
https://github.com/misht-world/dwg-shadow

INSTALL
  1. Close AutoCAD.
  2. Unzip the archive and double-click install.cmd.
  3. Start AutoCAD and type SHD (shadows) or SHDSERIES (shadow series).

  Manual install: copy the DwgShadow.bundle folder to
  %APPDATA%\Autodesk\ApplicationPlugins and unblock the files
  (Properties → Unblock) if Windows marked them as downloaded.

UNINSTALL
  Double-click uninstall.cmd.

DwgShadow — тени зданий для AutoCAD 2021–2024

УСТАНОВКА
  1. Закройте AutoCAD.
  2. Распакуйте архив и запустите install.cmd двойным щелчком.
  3. Запустите AutoCAD и введите SHD (тени) или SHDSERIES (серия теней).

  Вручную: скопируйте папку DwgShadow.bundle в
  %APPDATA%\Autodesk\ApplicationPlugins и снимите блокировку файлов
  (Свойства → Разблокировать), если Windows пометила их как скачанные.

УДАЛЕНИЕ
  Запустите uninstall.cmd.
